# Тест на соулмейта — предсвадебные испытания

Локальная браузерная игра для болтательного VTuber-стрима: ведущая панель, чистый экран для OBS и страница для зрителей с телефона.

## Быстрый запуск на Windows

1. Установи [Node.js LTS](https://nodejs.org/).
2. Открой папку проекта в терминале и выполни:

   ```powershell
   npm install
   npm run dev
   ```

3. Открой адрес, который покажет терминал (обычно `http://localhost:5173`).

## Как вести стрим — очень коротко

В OBS добавляется **один** постоянный Browser Source. В течение стрима его не нужно менять.

1. Открой панель ведущей: `http://localhost:5173`.
2. В OBS создай Browser Source 1920×1080 и вставь:

   `http://localhost:5173/screen?room=VIVI-HINA`

3. Открой этот источник в сцене с Виви и Хиночкой.
4. В панели ведущей просто нажимай режимы в левом меню: «Вопросы», «Бинго», «Суд», «Договор», «Рулетка» и т. д. Зрительский экран сменится сам примерно за секунду.

Необязательные страницы:

- Телефоны чата для голосования: `http://IP-АДРЕС-ТВОЕГО-ПК:5173/audience?room=VIVI-HINA`.
- Донатный стол и подключение DonationAlerts: `http://localhost:5173/donations`.
- Старый компактный оверлей с показателями: `http://localhost:5173/obs?room=VIVI-HINA`.

## Вдвоём и с чатом

### Ответы Виви и Хиночки

В четырёх играх с одновременным выбором — «Кто из нас», «Совпадём?», «Флаги» и «Что выберешь» — ведущая больше не вводит ответы за обеих.

1. На панели ведущей открой нужный режим.
2. В правой колонке нажми «Открыть планшет Виви» и отвечай на этой отдельной странице.
3. Скопируй Хиночке ссылку «Ссылка для Хиночки» и отправь ей в личные сообщения Discord.
4. На панели появится только «ответ отправлен» у каждой. Нажми «Раскрыть одновременно» — тогда ответы увидят вы и зрители.

Промпт и варианты находятся только на планшетах игроков. Поэтому ведущая не обязана заранее читать каждый раунд: она запускает режим, затем сама играет с личного планшета Виви.

### За что голосует чат

- «Кто из нас», «Совпадём?», «Флаги», «Что выберешь»: чат выбирает один из тех же вариантов. Его голос — мнение свадебной комиссии, а не замена вашим личным ответам.
- «Семейный суд»: чат выбирает вердикт — кто прав, виноваты оба или «развод».
- Бинго, тир-лист, договор, рулетка, вопросы и совместная жизнь: чат вмешивается сообщениями, предложениями и донатными событиями; отдельного голосования там нет, чтобы не плодить лишние кнопки.

Счёт голосов виден в правой колонке пульта. С одной страницы учитывается один голос, повторное нажатие меняет его.

### Хиночка и чат из другого дома

`localhost` работает только на твоём компьютере, поэтому для удалённого коллаба нужен публичный адрес на время стрима.

Сначала в `.env.local` задай два разных длинных ключа, например:

```text
VIVI_PLAYER_KEY=любой-длинный-случайный-текст-для-виви
HINA_PLAYER_KEY=другой-длинный-случайный-текст-для-хиночки
```

В PowerShell случайный ключ можно получить командой `[guid]::NewGuid().ToString("N")`. После изменения `.env.local` перезапусти `npm run dev`.

1. Оставь `npm run dev` открытым.
2. Установи `cloudflared` для Windows, затем в новом PowerShell выполни:

   ```powershell
   cloudflared tunnel --url http://localhost:5173
   ```

3. Скопируй адрес `https://…trycloudflare.com`, который появится в этом окне.
4. Замени `http://localhost:5173` в ссылке Хиночки на этот адрес, подставь её ключ и отправь ей, например:

   `https://…trycloudflare.com/player?room=VIVI-HINA&player=hina&key=ЗНАЧЕНИЕ_HINA_PLAYER_KEY`

   Для личного планшета Виви используй такой же адрес, но `player=vivi` и значение `VIVI_PLAYER_KEY`.

5. Ссылку для чата тоже сделай от этого адреса:

   `https://…trycloudflare.com/audience?room=VIVI-HINA`

Не публикуй ссылки с ключами в чате — это личные планшеты. Окно с туннелем и окно `npm run dev` должны оставаться открытыми до конца игры.

Чтобы подключить телефоны к зрительскому экрану, все устройства должны быть в одной Wi‑Fi сети. Windows может спросить разрешение для Node.js — выбери «Частные сети».

## Что уже работает

- 123 вопроса без повторов, ручной выбор номера;
- бинго 5×5 с новой карточкой и отметками;
- «Кто из нас», «Совпадём или разведёмся», Red Flag и «Что выберешь» с отдельными ответами Виви и Хиночки и одновременным раскрытием;
- тир-лист, семейный суд с таймером, договор с копированием и скачиванием;
- «Насколько ты меня знаешь», приданое, альтернативная жизнь, рулетка и финальный титул;
- шесть юмористических показателей, ручная корректировка и журнал событий;
- Единый пастельно-розово-бирюзовый зрительский экран: вопросы, варианты, бинго, суд, договор, тир-лист, рулетка и донаты автоматически получают состояние из панели ведущей.
- «Свадебная касса» DonationAlerts: 50–1000 ₽ открывают клятвы, семейный суд, договор, рулетку и другие события; алко‑тост за 150 ₽ — только добровольный символический глоток любого напитка.

## Подключение DonationAlerts

1. В папке проекта создай файл `.env.local` (не `.env.example`) и скопируй туда содержимое `.env.example`.
2. В личном кабинете DonationAlerts зарегистрируй приложение и укажи Redirect URI:

   `http://localhost:5173/api/donation-alerts/callback`

3. Вставь `DONATIONALERTS_CLIENT_ID` и `DONATIONALERTS_CLIENT_SECRET` в `.env.local`. Они должны оставаться только на твоём компьютере.
4. Перезапусти `npm run dev`, открой `/donations` и нажми «Подключить DonationAlerts».
5. Запусти «Тестовый донат» перед эфиром: он не списывает деньги, но проверяет очередь, панель ведущей и зрительский экран.

Можно вместо этого заполнить только `DONATIONALERTS_ACCESS_TOKEN`; это альтернативный способ подключения.

## Редактирование контента

Все вопросы, ситуации и карточки находятся в одном понятном файле:

`lib/game-data.ts`

Там можно менять тексты, добавлять свои пункты и удалить алкогольный сектор из `rouletteSectors`. Донатные пороги и эффекты находятся в `lib/donation-game.ts`. Алкогольная механика здесь добровольна: без таймеров, шотов и наказаний.

## Ограничение MVP

Страница зрителей отображает состояние комнаты в локальной сети, принимает по одному голосу с каждого устройства и показывает его ведущей. Интеграция с Twitch API пока не нужна для этой версии.
